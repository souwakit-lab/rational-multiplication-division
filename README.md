# 有理數乘除訓練場

以四個 Level 練習有理數乘除：

1. 兩個整數乘除，1,500 XP
2. 連乘、連除與簡單小數，500 XP
3. 括號、分數與帶分數，500 XP
4. 四則混合運算，500 XP

答對獲得 15 XP，答錯扣除 10 XP。答錯後會停留在原題，顯示詳細解答，學生按「下一題」才繼續。

每班的混沌乘除巨龍擁有 300,000 HP。老師可下載每名學生一行的總體及分 Level 統計；學生可下載自己的總體摘要和錯題紀錄。

## 本機預覽

```sh
python3 -m http.server 8080
```

學生頁：`http://localhost:8080/`

老師大屏：`http://localhost:8080/dashboard.html`
